# M01 — Foundation + Constitution

## Goal
Prove the product architecture end-to-end without pretending to have a complete medical knowledge base.

## Included
- React + TypeScript application.
- 16 baseline/master questions plus adaptive follow-ups.
- Deterministic visibility rules.
- Initial metabolic, cardiovascular, nutrition and sleep findings.
- Evidence completeness.
- Red-flag example flow.
- HAP-1.0 packet generator.
- AI assessment harness contract.
- Product constitution, vision and roadmap.

## Explicitly deferred
- Production-grade medical thresholds/rule sourcing.
- Medication interaction database.
- Pediatric assessment.
- Full women's-health / men's-health modules.
- Production authentication and persistence.
- Live external AI call.
- PDF lab extraction.

## Verification target
The app should build successfully, allow completion of the adaptive questionnaire, show traceable screening findings, and generate a JSON HAP packet suitable for use with the AI Harness.
