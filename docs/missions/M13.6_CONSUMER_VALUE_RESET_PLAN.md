# M13.6 — Consumer Value Reset: Health Intelligence Brief + Smart Recheck

Status: **PLANNED — NEXT MISSION**  
Effort: **High**  
Origin: Strategic Review 3

## Objective

Make the existing supported Jaanch scenarios feel dramatically more useful without expanding broad clinical scope.

The mission is successful only if a user can understand the result within seconds and a returning user can complete a routine recheck without rebuilding their profile.

## Scope

1. Replace the current card-heavy result with a one-screen **Health Intelligence Brief**.
2. Compress findings into at most 1–3 health priorities/themes.
3. Add deterministic cross-rule synthesis when several findings clearly belong to one priority cluster.
4. Each priority must answer:
   - what Jaanch sees;
   - why it matters for this person;
   - which evidence supports it;
   - the next best action;
   - what can wait;
   - what missing evidence would change the conclusion.
5. Demote evidence-completeness percentage from hero metric to detail.
6. Hide Profiles & mocks / protocol / runtime-debug surfaces from primary consumer navigation.
7. Implement **Smart Recheck** from the latest saved profile instead of blank-resetting answers/context/labs.
8. Separate stable profile facts from time-sensitive recheck fields.
9. Show a concise pre-save “what changed” confirmation.
10. Preserve evidence/provenance in expandable details.
11. Keep AI v2 optional; it cannot define the core Health Brief.

## Non-goals

- new broad clinical domains;
- more AI contracts or agents;
- cloud/auth/backend;
- mobile parity work;
- production/store hardening;
- Rule Studio;
- MCP/ChatGPT integration.

## Mock-specific value gates

### Low-risk adult
The first screen should reassure without pretending comprehensive health clearance. It should identify only genuinely decision-changing uncertainty and avoid generic wellness filler.

### Cardiometabolic + lipids
The product should synthesize waist/body composition, HbA1c, BP, LDL/TG and family history into a coherent cardiometabolic priority instead of presenting unrelated cards.

### Vegetarian + B12 + iron
The product should make coexistence of B12 and iron/anaemia evidence understandable, distinguish what is known vs causal uncertainty, and prioritize cause-oriented review rather than generic supplementation advice.

### Thyroid signal
The result should make the marked TSH signal and treatment context easy to understand without diagnosing or suggesting autonomous dose changes.

### Severe triglycerides
The result should make TG >=1000 the dominant priority over less-urgent lipid details and preserve clinician-review boundaries.

## Exit gate

For each of the five mocks, within 10 seconds of seeing the first result screen a user should be able to answer:

1. What is my top concern?
2. Why does Jaanch think that?
3. What should I do next?
4. What evidence matters next?

Returning-user gate:
- stable profile facts are prefilled from the latest check-in;
- the user is not forced to re-enter unchanged history/medications/body profile;
- a routine unchanged recheck should be substantially faster than first-time intake;
- Jaanch clearly previews what changed before saving.

## Product north star

> Does this materially improve what a user understands or can decide within 60 seconds?

If not, it does not belong in M13.6.
