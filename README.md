# Jaanch

**Jaanch** is a deterministic, evidence-aware personal health assessment and prevention engine.

It uses adaptive questioning, transparent rules, evidence gaps, safety gates, and an optional constrained AI review layer. The deterministic engine remains authoritative; AI is harnessed through a strict Markdown protocol and standardized output contract.

## Core principles

- Ask high-information master questions first.
- Reveal only relevant follow-up modules.
- Separate risk, suspicion, evidence, and confirmed findings.
- Explain why each question, test, or action is recommended.
- Keep red flags and special-population safety gates deterministic.
- Treat AI as an optional constrained reviewer/explainer, not an autonomous doctor.
- Keep every rule traceable, versioned, testable, and medically reviewable.

The product constitution, AI harness, roadmap, and mission system live under `docs/`.
